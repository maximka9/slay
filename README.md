# CAMCA63 AWARDS 2026

Публичное голосование и интерактивный сайт церемонии Twitch-канала **camca63**. Проект содержит 9 номинаций, 21 автоматически созданную сцену, 52 превью и 60 видеороликов. Зрители входят через Twitch и голосуют, а владелец канала модерирует голоса, фиксирует результаты и проводит церемонию без раскрытия победителей в публичной сборке.

Стек: React 19, TypeScript, Vite, React Router, Cloudflare Pages Functions, D1, Twitch OAuth и Playwright. Шрифты, изображения и видео загружаются локально.

## Запуск

Требуется Node.js 22.12 или новее.

```powershell
cd R:\Python\SLAY
npm ci
Copy-Item .dev.vars.example .dev.vars
npm run db:migrate:local
npm run dev:cloudflare
```

Заполните в `.dev.vars` данные локального Twitch-приложения. Wrangler откроет сайт, обычно на `http://localhost:8788`. Обычный `npm run dev` остаётся доступен для работы только с интерфейсом и церемонией.

- `/` и `/awards` — обзор девяти номинаций;
- `/vote` — публичное голосование;
- `/admin` — закрытая панель владельца канала;
- `/present` — режим ведущего;
- `/present?scene=3` — восемь инди-игр;
- `/present?scene=5` — десять игр года;
- `/present?scene=7` — ивенты;
- `/present?scene=9` — ИРЛ с друзьями и кукинг;
- `/present?scene=11` — семь клипов Dota 2;
- `/present?scene=13` — завозы от комьюнити;
- `/present?scene=15` — восемь фейлов;
- `/present?scene=19` — чаттер года;
- `/present?scene=21` — финал;
- `/results` — архив результатов.
- `/privacy` — состав и сроки хранения данных.

Полная настройка Twitch, D1 и Cloudflare Pages описана в [docs/cloudflare-deployment.md](docs/cloudflare-deployment.md). До добавления настоящих секретов и развёртывания публичный адрес отсутствует.

## Сопоставление медиа

Один объект `Nominee` соответствует одной карточке. Его поле `videos` может содержать несколько роликов:

```ts
{
  id: 'game-4',
  name: 'Red Dead Redemption 2',
  media: {
    src: '/assets/nominees/game/Red Dead Redemption 2.jpg',
    alt: 'Обложка Red Dead Redemption 2',
  },
  videos: [
    { src: '/assets/nominees/game/videos/rdr-1.mp4', label: 'Red Dead Redemption 2 — видео 1' },
    { src: '/assets/nominees/game/videos/rdr-2.mp4', label: 'Red Dead Redemption 2 — видео 2' },
  ],
}
```

Сопоставления задаются явно, поэтому серии файлов не превращаются в лишние карточки. Сейчас настроены:

- 8 инди-игр, включая три ролика No, I'm Not a Human и ролик Who's Lila?;
- 10 игр года, включая серии Resident Evil 2, Resident Evil 4, Red Dead Redemption 2 и The Last of Us Part I;
- 6 ивентов: «Что? Где? Когда? №1», «Что? Где? Когда? №2», «Чудо-полес», «Где логика?», «Новогодний турнир» и The International 141;
- 6 выпусков в объединённой категории ИРЛ: три поездки и встречи плюс три кукинга;
- 7 отдельных клипов Dota 2;
- 7 отдельных завозов от комьюнити;
- 8 отдельных фейлов.

Все исходные MP4 проверены через FFprobe: видео H.264, звук AAC, пиксельный формат yuv420p. Перекодирование не требуется. Runtime-файлы находятся в `public/assets/nominees/`.

### Подготовка файлов и превью

Команда копирует только используемые материалы из исходных папок и создаёт отсутствующие превью через FFmpeg:

```powershell
npm run prepare:media
```

Готовое изображение всегда имеет приоритет. FFmpeg используется для 24 карточек без отдельной обложки: чат-рулетка, пицца, семь завозов, семь клипов Dota 2 и восемь фейлов. Кадры берутся примерно на четвёртой секунде, сохраняются в `public/assets/generated-previews/` и не создаются при запуске сайта.

Таблица копирования и точки кадров находятся в `scripts/prepare-media.ps1`. Скрипт проверяет контейнер и кодеки через FFprobe и записывает размеры, длительность и совместимость с лимитом Pages в `artifacts/media-preparation-v7.json`. Для пересоздания существующих файлов запустите скрипт с параметром `-Force` через PowerShell с чтением UTF-8 либо удалите нужное готовое превью перед `npm run prepare:media`.

Исходные папки остаются локально и исключены из Git, чтобы не хранить второй экземпляр крупных файлов. Все используемые сайтом копии входят в репозиторий в `public/assets`.

## Просмотр материалов

Карточка с видео показывает отдельную кнопку «Включить клипы» (для одного ролика — «Смотреть клип») и открывает плеер внутри сайта. Карточка без видео остаётся обычной некликабельной обложкой: у неё нет Play, кнопки просмотра, курсора-ссылки и клавиатурного открытия. На странице голосования кнопка «Выбрать» работает независимо от кнопки просмотра и никогда не запускает видео.

Плеер поддерживает:

- стандартные Play/Pause, перемотку, громкость и полноэкранный режим;
- предыдущее, следующее и повтор текущего ролика;
- показ всего исходного кадра с учётом фактических размеров видео;
- автоматическую очередь роликов одного номинанта с фиксированной паузой 2 секунды;
- приостановку межроликового отсчёта;
- остановку очереди после последнего ролика номинанта;
- сообщения об ошибке загрузки;
- немедленную остановку при закрытии.

| Клавиша в плеере | Действие |
|---|---|
| Space | Пауза / продолжить |
| ← / → | Предыдущий / следующий ролик |
| M | Звук |
| F | Полноэкранное видео |
| Esc | Закрыть плеер |

Пока плеер открыт, эти клавиши не переключают сцены церемонии.

## Управление церемонией

| Действие | Клавиши |
|---|---|
| Следующая сцена | →, PageDown, Space |
| Предыдущая сцена | ←, PageUp |
| Объявить победителя | Enter или кнопка |
| Первая / последняя сцена | Home / End |
| Полный экран | F или «А» в русской раскладке |
| Закрыть окно / выйти из полного экрана | Esc |
| Скрыть / показать нижнюю панель | H |

Раскрытия сохраняются в `sessionStorage`. Переход вперёд со сцены победителя блокируется до раскрытия. В production `/present` доступен администратору только после полной серверной проверки готовности: голосование закрыто, снимок актуален, в каждой активной номинации есть ровно один победитель либо явно указано «Без победителя», а у победителя есть доступное изображение. Неполный снимок не передаёт победителей в интерфейс. Для безопасной репетиции администратор использует `/present?rehearsal=1`; реальные победители туда не загружаются.

## Голосование и результаты

D1 обеспечивает один голос на Twitch ID в каждой обычной номинации. Повторный выбор меняет существующий голос и сохраняет историю. Для «Вашей номинации» один Twitch ID хранит одно изменяемое текстовое предложение. Исключение при модерации меняет статус записи и автоматически влияет на текущий подсчёт.

Голосование управляется одним глобальным статусом: `preparation`, `open` или `closed`. Расписания, дат начала и окончания и независимых статусов категорий в рабочей логике нет. Переход в подготовку или повторное открытие сохраняет голоса и снимки, но начинает новый цикл публичной видимости, поэтому ранее опубликованные результаты не раскрываются после следующего закрытия автоматически.

В верхней части `/admin` находятся отдельные кнопки запуска репетиции и боевой церемонии. Репетиция всегда использует демонстрационные результаты; боевая кнопка активируется только после серверной проверки готовности. Итоговый и промежуточный подсчёты показывают топ-3 с независимым раскрытием полного списка, а журнал аудита загружает по три последние записи и открывает остальную историю постранично.

Победители не записываются в `src/data/awards.ts` и не попадают в JavaScript-сборку. После закрытия администратор создаёт серверный снимок, разрешает ничьи или явно отмечает номинацию без победителя и публикует все основные либо выбранные номинации. «Ваша номинация» имеет отдельный флаг публикации, по умолчанию скрыта и раскрывается только прямой командой администратора. `/present` получает неопубликованных победителей только из защищённого административного API; `/results` получает записи текущего цикла публикации. Любое изменение голосов или кандидатов сразу скрывает устаревший публичный снимок до повторной фиксации.

Перед финальной фиксацией создайте резервную копию командой `npm run db:backup`. После завершения премии можно удалить персональные данные, сохранив итоговые снимки; процедура приведена в документации развёртывания.

Тесты проверяют ограничения базы и секретность результатов между циклами публикации, независимую публикацию «Вашей номинации», сохранение старых голосов миграциями, единый статус без расписания, 9 номинаций и 21 сцену, некликабельные карточки без видео, сетки на 1920×1080, 1366×768 и 1280×720, очередь роликов, изоляцию клавиатуры плеера, архив, контраст и наличие всех 52 превью и 60 видео в локальной production-сборке.
