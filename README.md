# CAMCA63 AWARDS 2026

Интерактивный сайт церемонии Twitch-канала **camca63**. В проекте 19 управляемых сцен, восемь номинаций, ручное раскрытие победителей, полноэкранный режим и отдельный архив результатов. Сайт собран на React, TypeScript и Vite; шрифты и все активные изображения хранятся локально.

## Запуск

Требуется Node.js 22.12 или новее.

```powershell
cd R:\Python\SLAY
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, обычно `http://127.0.0.1:5173`. Также можно запустить `START.cmd`.

- `/` и `/awards` — обзор восьми номинаций;
- `/present` — церемония с первой сцены;
- `/present?scene=3` — «Чаттер года»;
- `/present?scene=5` — восемь инди-игр;
- `/present?scene=7` — десять игр года;
- `/results` — архив, закрытый до публикации.

## Содержание

Весь редакционный контент находится в `src/data/awards.ts`. Номинации идут в таком порядке:

1. Чаттер года
2. Инди-игра года
3. Игра года
4. Ивент года
5. Алкострим года
6. Кукинг года
7. Клип года
8. Мем года

Каждая номинация занимает две сцены: представление и объявление победителя. Вместе с обложкой, программой и финалом получается **19 сцен**. Номера сцен и номинаций рассчитываются автоматически.

«Чаттер года» не содержит заранее заданного списка кандидатов. На сцене показано тематическое оформление Twitch-чата. После голосования победитель задаётся отдельным объектом:

```ts
{
  id: 'chatter',
  // остальные поля категории
  winnerId: null,
  winner: {
    id: 'chatter-winner',
    name: 'Ник победителя',
    media: {
      src: '/assets/winners/chatter.webp',
      alt: 'Аватар победителя номинации Чаттер года',
    },
    description: 'Необязательная подпись',
  },
}
```

Файл аватара в этом примере нужно положить в `public/assets/winners/chatter.webp`. Пока `winner: null`, результат не задан.

В остальных категориях укажите `winnerId` существующего заполненного кандидата:

```ts
winnerId: 'game-1',
```

Имя, изображение и описание автоматически берутся из объекта кандидата. Значение `null` оставляет победителя нераскрытым. Конфигурационная проверка обнаруживает дубли ID, пустые данные победителя и неверные ссылки.

### Игры

В `public/assets/nominees/indie-game/` находятся восемь обложек инди-игр. В `public/assets/nominees/game/` находятся десять обложек основной номинации:

| ID | Название |
|---|---|
| game-1 | Heavy Rain |
| game-2 | Resident Evil 2 |
| game-3 | Resident Evil 4 |
| game-4 | Red Dead Redemption 2 |
| game-5 | The Last of Us Part I |
| game-6 | The Witcher 3: Wild Hunt |
| game-7 | The Last of Us Part II |
| game-8 | Black Myth: Wukong |
| game-9 | Resident Evil 7: Biohazard |
| game-10 | Clair Obscur: Expedition 33 |

На десктопе десять игр размещаются сеткой 5×2 на одной сцене. Исходные файлы из папок `indi` и `games` скопированы без перекодирования.

В категориях «Ивент года», «Алкострим года», «Кукинг года», «Клип года» и «Мем года» оставлены по четыре пустых слота. Заполните их объектами `Nominee` по существующим примерам. Изображение кладётся в `public/assets/nominees/<категория>/`, а путь в конфиге начинается с `/assets/`.

Для локального видео используйте:

```ts
media: {
  src: '/assets/video/clip.mp4',
  type: 'video',
  poster: '/assets/nominees/clip/preview.webp',
  alt: 'Название клипа',
},
```

MP4 и WebM запускаются только по действию пользователя. Внешнюю ссылку на Twitch-клип можно указать в `clipUrl`.

## Управление церемонией

| Действие | Клавиши |
|---|---|
| Следующая сцена | →, PageDown, Space |
| Предыдущая сцена | ←, PageUp |
| Объявить победителя | Enter или кнопка |
| Первая / последняя сцена | Home / End |
| Полный экран | F или «А» в русской раскладке |
| Закрыть окно / выйти из полного экрана | Esc |
| Скрыть / показать нижнюю панель | H |

Переход вперёд со сцены победителя блокируется до раскрытия. Для репетиции есть кнопка «Пропустить сцену». Раскрытия хранятся в `sessionStorage` текущей вкладки и сбрасываются через настройки церемонии.

## OBS и production-сборка

```powershell
npm run build
npm run preview
```

Откройте `http://127.0.0.1:4173/present` в Chrome или Edge. Рекомендуемые размеры: 1920×1080, 1366×768 или 1280×720 при масштабе 100%. Добавьте окно браузера в OBS через «Захват окна», нажмите F и оставьте фокус в браузере для управления клавишами. Режим «Облегчённые эффекты» снижает количество анимации.

Шрифты и изображения загружаются локально, поэтому интернет для проведения церемонии не требуется.

## Архив

После церемонии установите `ceremonyPublished: true` в `src/data/awards.ts` и соберите проект заново. Страница `/results` покажет заданных победителей, кандидатов и медиа. Категории без победителя будут отмечены как неопубликованные.

Статическая сборка содержит заданные результаты даже при закрытом архиве. До эфира храните сборку в закрытом окружении.

## Проверки

```powershell
npm test
npm run build
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npm run test:e2e
npm run test:production
```

Тесты проверяют структуру из восьми номинаций и 19 сцен, отсутствие удалённых участников в активных данных, все локальные изображения, сетки 8 и 10 игр, навигацию, ручное раскрытие, полноэкранный режим, мобильную ширину, архив и production-сборку. Контраст проверяется axe-core и отдельным пиксельным аудитом; отчёт сохраняется в `artifacts/contrast-audit.json`.

Тестовый победитель подставляется только в браузерном тесте. Он не записывается в исходный конфиг и не является результатом премии.

## Структура проекта

```text
src/data/awards.ts                  — номинации, кандидаты и победители
src/data/scenes.ts                  — генерация 19 сцен и состояние раскрытий
src/pages/                          — обзор, церемония и архив
src/components/                     — карточки, медиа, иконки и SVG-кубок
src/styles/main.css                 — адаптивный дизайн и анимации
public/assets/nominees/game/        — 10 обложек игры года
public/assets/nominees/indie-game/  — 8 обложек инди-игр
public/assets/winners/              — материалы победителей без списка кандидатов
tests/                              — конфигурационные и браузерные проверки
artifacts/                          — отчёты и проверочные скриншоты
```

Презентация `CAMCA63_AWARDS_2026_NEON.pptx` использована как визуальный ориентир. Все сцены реализованы компонентами сайта.
