# CAMCA63 AWARDS 2026

Интерактивный сайт церемонии Twitch-канала **camca63**. Проект содержит 9 номинаций, 21 автоматически созданную сцену, 38 превью и 47 локальных видеороликов. Ведущий может просматривать материалы, управлять очередями видео и отдельно объявлять победителей.

Стек: React 19, TypeScript, Vite, React Router и Playwright. Шрифты, изображения и видео загружаются локально.

## Запуск

Требуется Node.js 22.12 или новее.

```powershell
cd R:\Python\SLAY
npm ci
npm run dev
```

Откройте адрес Vite, обычно `http://127.0.0.1:5173`. Также можно запустить `START.cmd`.

- `/` и `/awards` — обзор девяти номинаций;
- `/present` — режим ведущего;
- `/present?scene=3` — восемь инди-игр;
- `/present?scene=5` — десять игр года;
- `/present?scene=7` — ивенты;
- `/present?scene=9` — ИРЛ с друзьями и кукинг;
- `/present?scene=13` — завозы от комьюнити;
- `/present?scene=15` — рейджи;
- `/present?scene=19` — чаттер года;
- `/present?scene=21` — финал;
- `/results` — архив результатов.

## Сопоставление медиа

Один объект `Nominee` соответствует одной карточке. Его поле `videos` может содержать несколько роликов:

```ts
{
  id: 'game-4',
  name: 'Red Dead Redemption 2',
  media: {
    src: '/assets/nominees/game/Red Dead Redemption 2.jpg',
    alt: 'Обложка Red Dead Redemption 2',
  },
  videos: [
    { src: '/assets/nominees/game/videos/rdr-1.mp4', label: 'Red Dead Redemption 2 — видео 1' },
    { src: '/assets/nominees/game/videos/rdr-2.mp4', label: 'Red Dead Redemption 2 — видео 2' },
  ],
}
```

Сопоставления задаются явно, поэтому серии файлов не превращаются в лишние карточки. Сейчас настроены:

- 8 инди-игр, включая три ролика No, I'm Not a Human и ролик Who's Lila?;
- 10 игр года, включая серии Resident Evil 2, Resident Evil 4, Red Dead Redemption 2 и The Last of Us Part I;
- 5 ивентов: «Что? Где? Когда?», «Чудо-полес», «Где логика?», «Новогодний турнир» и The International 141;
- 6 выпусков в объединённой категории ИРЛ: три поездки и встречи плюс три кукинга;
- 7 отдельных завозов от комьюнити;
- 2 отдельных рейджа.

Все исходные MP4 проверены через FFprobe: видео H.264, звук AAC, пиксельный формат yuv420p. Перекодирование не требуется. Runtime-файлы находятся в `public/assets/nominees/`.

### Подготовка файлов и превью

Команда копирует только используемые материалы из исходных папок и создаёт отсутствующие превью через FFmpeg:

```powershell
npm run prepare:media
```

Готовое изображение всегда имеет приоритет. FFmpeg используется для 11 карточек без отдельной обложки: чат-рулетка, пицца, семь завозов и два рейджа. Кадры сохраняются в `public/assets/generated-previews/` и не создаются при запуске сайта.

Таблица копирования и точки кадров находятся в `scripts/prepare-media.ps1`. Для пересоздания существующих файлов запустите скрипт с параметром `-Force` через PowerShell с чтением UTF-8 либо удалите нужное готовое превью перед `npm run prepare:media`.

Исходные папки остаются локально и исключены из Git, чтобы не хранить второй экземпляр крупных файлов. Все используемые сайтом копии входят в репозиторий в `public/assets`.

## Просмотр материалов

Карточка с видео отмечена значком Play. Нажатие открывает модальное окно внутри сайта. Карточка без видео открывает увеличенное изображение.

Плеер поддерживает:

- стандартные Play/Pause, перемотку, громкость и полноэкранный режим;
- предыдущее, следующее и повтор текущего ролика;
- показ всего исходного кадра с учётом фактических размеров видео;
- автоматическую очередь роликов одного номинанта с фиксированной паузой 2 секунды;
- приостановку межроликового отсчёта;
- остановку очереди после последнего ролика номинанта;
- сообщения об ошибке загрузки;
- немедленную остановку при закрытии.

| Клавиша в плеере | Действие |
|---|---|
| Space | Пауза / продолжить |
| ← / → | Предыдущий / следующий ролик |
| M | Звук |
| F | Полноэкранное видео |
| Esc | Закрыть плеер |

Пока плеер открыт, эти клавиши не переключают сцены церемонии.

## Управление церемонией

| Действие | Клавиши |
|---|---|
| Следующая сцена | →, PageDown, Space |
| Предыдущая сцена | ←, PageUp |
| Объявить победителя | Enter или кнопка |
| Первая / последняя сцена | Home / End |
| Полный экран | F или «А» в русской раскладке |
| Закрыть окно / выйти из полного экрана | Esc |
| Скрыть / показать нижнюю панель | H |

Раскрытия сохраняются в `sessionStorage`. Переход вперёд со сцены победителя блокируется до раскрытия; для репетиции есть кнопка «Пропустить сцену».

Победители не заполнены. Для обычной категории задайте существующий `winnerId`. У «Чаттера года» победитель задаётся отдельным объектом `winner`, поскольку списка кандидатов у этой номинации нет.

## OBS и production

```powershell
npm run build
npm run preview
```

Откройте `http://127.0.0.1:4173/present` в Chrome или Edge. Проверенные размеры: 1920×1080, 1366×768 и 1280×720 при масштабе 100%. Видео загружается только после открытия карточки; одновременно работает один плеер. При закрытии модального окна воспроизведение и звук останавливаются.

Для OBS используйте «Захват окна». Оставьте фокус в браузере для клавиатурного управления. Режим «Облегчённые эффекты» уменьшает количество анимации.

## Архив

После церемонии установите `ceremonyPublished: true` в `src/data/awards.ts` и пересоберите проект. `/results` покажет победителей и кандидатов. Статическая сборка содержит заданные результаты даже при закрытом архиве, поэтому до эфира храните её в закрытом окружении.
